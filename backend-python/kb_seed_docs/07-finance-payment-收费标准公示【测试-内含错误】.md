# 2026—2027学年收费标准公示

发文单位：计划财务处
发布日期：2026年8月10日
说明：本公示仅供缴费参考，具体以当年录取通知书及财务系统核定金额为准。

## 一、本科学费标准

| 专业类别 | 学费（元/学年） |
| --- | --- |
| 文史类 | 4800 |
| 理工类 | 5000 |
| 计算机科学与技术、软件工程 | 5000 |
| 艺术类 | 9000 |
| 中外合作办学 | 28000 |

## 二、住宿费标准

| 宿舍类型 | 收费（元/学年） |
| --- | --- |
| 四人间（独立卫浴） | 1500 |
| 四人间（公共卫浴） | 1200 |
| 六人间 | 900 |

## 三、缴费截止时间

1. 2026级新生缴费截止日期为 **2026年2月30日**，逾期按自动放弃入学资格处理；
2. 老生秋季学期缴费截止 9 月 10 日，春季学期缴费截止 3 月 5 日。

## 四、预收与结算

1. 计算机类专业（计算机科学与技术、软件工程）按 **6500元/学年** 预收，学年末按实际学分结算，多退少补；
2. 实验材料费按专业实际消耗据实收取，单专业每学年不超过 800 元。

## 五、退费规定

1. 学生因故退学的，**开学一个月内**提出申请的，按实际就读时间折算后退还剩余学费的 90%；
2. 逾期申请的，按就读月份折算退费；
3. 开学后一律不办理任何形式的学费退还。

## 六、国家助学贷款

1. 校园地国家助学贷款额度上限为 **12000元/学年**，研究生同标准；
2. 生源地信用助学贷款按户籍地资助中心政策执行，回执码录入截止 10 月 15 日。

## 七、其他代收费

1. 新生体检费 120 元/人（入学时一次性收取）；
2. 大学生医保按杭州市当年公布标准代收；
3. 教材费按实际订购结算，毕业时统一结清，多退少补。
