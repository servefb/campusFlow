第四条 学生申请国家奖学金须符合以下基本条件：
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守学校规章制度，在校期间无任何违规违纪处分；
（三）诚实守信，道德品质优良；
（四）在校期间学习成绩优异，社会实践、创新能力、综合素质等方面表现特别突出。

第七条 学习成绩排名与综合考评成绩排名均位于前10%（含10%）的学生，可以申请国家奖学金。学习成绩排名和综合考评成绩排名均位于前10%~30%（含30%）的学生，在道德风尚、学术研究、学科竞赛、创新发明等某一方面表现特别优秀者，亦可申请，但需提交由校专家委员会组织审议认可的证明材料。

校资助委审核批注：大二学年参评直接以第一学年综测档案库（已于9月30日封存）为核定基准。
