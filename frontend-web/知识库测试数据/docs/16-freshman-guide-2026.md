# 2026级本科生入学须知

- 文号：（无正式文号，校内通知类文件）
- 发布单位：党委学生工作部 教务处 后勤保障部
- 发布日期：2026-08-30
- 效力状态：现行有效（通知类）
- 适用对象：2026级本科新生

## 一、报到时间与地点

1. 报到时间为2026年9月5日至9月6日，每日8:00至18:00。
2. 报到地点设在大学生活动中心一层大厅，各学院设有独立接待工位。
3. 因故不能按期报到的，应提前向所在学院请假，请假期限一般不超过两周。

## 二、报到所需材料

1. 录取通知书原件。
2. 身份证原件及复印件两份。
3. 近期免冠证件照六张（白底，一寸）。
4. 党团组织关系转接材料。
5. 户口迁移材料（自愿办理）。

## 三、缴费与绿色通道

1. 学费与住宿费可通过线上缴费平台缴纳，缴费通道自8月28日开放。
2. 家庭经济困难的新生可通过绿色通道先行办理入学手续，入学后再按《家庭经济困难学生认定办法》申请资助。
3. 已在生源地办理助学贷款的学生，凭贷款受理证明免交学费。

## 四、住宿安排

1. 新生宿舍由后勤保障部统一分配，床位信息在报到前通过线上系统公布。
2. 宿舍生活用品可到校内超市自行采购，学校不统一配发床上用品。
3. 宿舍内禁止使用大功率电器，详见《学生宿舍用电与消防安全细则》。

## 五、入学教育

1. 入学教育安排在报到后一周内进行，内容包括校史校情、学籍管理、安全教育与心理健康教育。
2. 新生须参加入学资格复查与体检，体检安排在9月7日至9月10日，地点为校医院。
3. 入学教育考核不合格的，需在两周内补学补考。

## 六、军训安排

1. 军训时间为9月11日至9月24日，地点为学校运动场。
2. 因身体原因不能参加军训的，须提交二级甲等以上医院证明，经学院审核后安排随训或缓训。

## 七、安全提示

1. 报到期间人员密集，请妥善保管录取通知书、身份证件与随身财物。
2. 学校不会以任何名义要求新生向私人账户转账，遇到可疑情况请拨打校内报警电话6100119。
