# 知识库检索验证用例（ground truth）

> 用途：文件上传入知识库、解析切片完成后，按本表逐条核对检索与引用是否正确。
> 「期望命中」指文档，条款级期望写在「应命中的条款」列。
> 判定口径以接口文档 A.6.2 为准：**标题 / 文号 / 正文任一命中即返回**（不是三处同时命中）。

## 三、版本与效力（同名不同版）

| # | 场景 | 操作 | 期望 |
| --- | --- | --- | --- |
| 3.1 | 归档版可见性 | `query=国家奖学金&validity=archive` | 只返回 02 |
| 3.2 | 现行过滤 | `query=国家奖学金&validity=current` | 只返回 01，**不得返回 02** |
| 3.3 | 修订态 | `query=学籍管理&validity=revised` | 只返回 04 |
| 3.4 | 版本冲突落库 | 上传完成后查 `GET /knowledge/admin/conflicts` | 出现两组待处理冲突：01↔02（同名新版本替代归档版）、03↔04（同名现行版存在未发布的修订稿） |
| 3.5 | 回答口径 | 问助手「国家奖学金现在要求排名前多少？」 | 引 01 第五条（前10%），**不得引 02 的「前15%」** |
| 3.6 | 历史沿革问法 | 问助手「2024年的国奖要求是什么？」 | 允许引 02，且应说明该办法已被替代 |

## 五、分页、排序与计数

| # | 场景 | 期望 |
| --- | --- | --- |
| 5.1 | 无参 `page=1&page_size=20` | `status=ready` 共 16 篇（新增 13 篇 + 库内已有 29/30/31）；含归档则 18 篇（+02、+32） |

## 七、引用可追溯

| # | 检查项 | 要求 |
| --- | --- | --- |
| 7.1 | 引用三件套 | `message_citations` 的 `document_id / version_id / section_id` 都要能落到真实记录，且 `section_id` 属于该 `version_id` |
| 7.2 | id 同源 | A.6.3/A.6.5 返回的 `document_id`、`section_id` 与列表接口一致（用于 `/knowledge?doc={id}` 跳转） |
| 7.3 | 重叠条款择一 | 05 第十二~十三条与 09 第六条语义重叠，问「综测公示几天」时应引 05 第十二条（原文 3 个工作日），问「奖学金公示几天」时引 09 第四条（5 个工作日） |
| 7.4 | 无正文不入引用 | 15（draft）与 04（draft）**不得**出现在任何引用里 |
